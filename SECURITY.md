# Security Policy

## Scope

The current repository contains documentation and development tooling only.
Security-sensitive implementation policies will be defined before application,
MCP, or Azure components are introduced.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use a private GitHub
Security Advisory or contact the repository maintainers through the private
channel configured for this repository.

Include:

- A clear description of the issue.
- Reproduction steps or proof of concept.
- Affected files, workflows, or versions.
- Suggested mitigation, if known.

Please allow maintainers reasonable time to investigate and coordinate
disclosure.
