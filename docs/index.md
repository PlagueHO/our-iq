# Our IQ documentation

Our IQ is a proposed, repository-backed knowledge server for teams and
organizations. This site records the project vocabulary, requirements,
architecture exploration, decisions, and future usage guidance.

## Start here

| Area | Purpose |
| --- | --- |
| [Tutorials](tutorials/) | Learning-oriented paths for a future contributor or user. |
| [How-to guides](how-to/) | Task-oriented procedures for maintaining the repository. |
| [Reference](reference/) | Precise descriptions of repository conventions and interfaces. |
| [Explanation](explanation/) | Concepts, rationale, and design context. |
| [Design](design/) | Product requirements, architecture, decisions, and documentation skills. |

## Documentation status

This site is a scaffold. Pages with `Proposed` status are templates or
questions for review, not committed product behavior.
