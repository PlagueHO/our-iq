## 4. Solution strategy

## Purpose

Summarize the decisions that shape the solution and map them to requirements.

## Current strategy

No implementation strategy has been approved. The current strategy is to
discover requirements and architecture through reviewable documents.

## Candidate principles

- Repository-backed source of truth.
- Human governance for consequential changes.
- Explicit provenance and lifecycle state.
- Secure-by-default agent boundaries.

These principles require validation before becoming architecture constraints.

## Open questions

- Which principles are mandatory?
- What is the smallest useful architecture to validate first?
